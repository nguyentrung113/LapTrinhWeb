# Website Thương mại điện tử (E-commerce Web Application)

## Giới thiệu

Đây là dự án cá nhân được thực hiện trong khuôn khổ môn học Lập trình Web. Dự án xây dựng một website thương mại điện tử nhằm vận dụng kiến thức phát triển web và triển khai các chức năng cơ bản của một hệ thống mua sắm trực tuyến.

## Công nghệ sử dụng

- **Ngôn ngữ lập trình:** C#
- **Framework:** ASP.NET Core MVC
- **Cơ sở dữ liệu:** SQL Server
- **Frontend:** HTML, CSS, JavaScript

## Chức năng chính

- Giao diện dành cho khách hàng và quản trị viên (Admin).
- Tìm kiếm sản phẩm (Product Search).
- Lọc sản phẩm theo điều kiện (Product Filtering).
- Quản lý giỏ hàng (Shopping Cart).
- Xử lý đặt hàng (Checkout).
- Xác thực người dùng (Authentication).
- Kết nối và thao tác với cơ sở dữ liệu.

## Vai trò thực hiện

Đây là dự án cá nhân, được thực hiện trong quá trình học môn Lập trình Web. Tôi phụ trách phát triển các chức năng của website và áp dụng kiến thức ASP.NET Core MVC, SQL Server vào xây dựng ứng dụng.
